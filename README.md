# othello-bot

Discord のチャンネルでオセロを遊べる Bot です。1 局につきメッセージは 1 つで、石を打つたびにそのメッセージが更新されます。

## できること

- ほかのメンバーとの対局（相手を指名、または誰でも参加できる募集）
- CPU との対局（弱い・普通・強い、先手・後手を選択）
- ボタンでの着手（列 a〜h を押してから行 1〜8 を押す）と、座標を指定するコマンドでの着手
- 盤面の表示を「画像」と「文字（絵文字）」から選択
- 引き分けの提案・投了
- 棋譜の表示（`f5d6c3...` の形式。対局中も表示）と、終局時のリプレイ GIF（着手がない場合は GIF なし）
- Bot を再起動しても、進行中の対局をそのまま続けられます

## コマンド

| コマンド | 説明 |
| --- | --- |
| `/othello play [opponent] [display]` | 対局を申し込みます。`opponent` を省略すると誰でも参加できる募集になります。実行した人が先手（黒）です。 |
| `/othello cpu [level] [color] [display]` | CPU と対局します。`color` で自分の先手・後手を選べます。 |
| `/othello place position` | 座標（例: `d3`）を指定して打ちます。入力中は打てる場所が候補に出ます。 |
| `/othello help` | 遊び方を表示します（自分にだけ表示）。 |

`display` を省略すると画像で表示します。

## 注意

- 1 人が同じチャンネルで同時に参加できる対局は 1 つまでです。申し込み中・募集中の対局も含みます。
- 対局は SQLite のファイル（既定は実行したディレクトリの `othello.db`）に保存されます。このファイルを消すと、進行中の対局は続けられなくなります。
- 24 時間操作がない対局は中断されます。
- 対局メッセージを削除すると、その対局は終了扱いになります。
- 文字モードの盤面には、Bot が起動時に自動で登録するアプリケーション絵文字（名前が `oth<版>_` で始まるもの）を使います。絵文字の見た目を更新したときは、古い版の絵文字を Bot が削除します。

## 導入

必要なもの: [uv](https://docs.astral.sh/uv/)、Discord の Bot アプリケーション

1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作り、Bot のトークンを発行します。特権インテントは不要です。
2. OAuth2 の URL Generator で、スコープ `bot` と `applications.commands`、権限「チャンネルを見る」「メッセージを送信」を選び、生成した URL から Bot をサーバーに招待します。
3. このリポジトリで依存関係を入れ、トークンを設定して起動します。

```sh
uv sync
echo 'DISCORD_TOKEN=<Bot のトークン>' > .env
uv run --env-file .env othello-bot
```

起動時にスラッシュコマンドの登録と、文字モード用の絵文字の登録を行い、保存してある進行中の対局を再開します。

対局の保存先を変えるときは、環境変数 `OTHELLO_DB` にファイルのパスを指定します。
